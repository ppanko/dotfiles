* Startup

Package bootstrap and dependency recovery are handled in =init.el= before this
literate configuration is loaded. Keep source selection, compilation, secrets,
and Windows Rtools/MSYS2 discovery explicit here because their order affects
all later local modules and subprocesses.

#+BEGIN_SRC emacs-lisp
  (setq load-prefer-newer t)

  (use-package auto-compile
    :demand t
    :config
    (auto-compile-on-load-mode)
    (auto-compile-on-save-mode))
#+END_SRC

Load machine-local secrets before platform discovery so Windows Rtools and R
overrides are available when their respective setup stages run.

#+BEGIN_SRC emacs-lisp
  (defconst p3/secrets-file
    (expand-file-name "secrets.el" user-emacs-directory)
    "Private configuration file loaded outside version control.")
  (when (file-exists-p p3/secrets-file)
    (load-file p3/secrets-file))
#+END_SRC

Platform-specific discovery lives in =lisp/p3-platform.el=. On Windows, select
the Rtools/MSYS2 environment here so Git and other subprocess-using packages
see its Unix tools early in startup. R and shell configuration remain in their
original subsystem sections below.

#+BEGIN_SRC emacs-lisp
  (eval-and-compile
    (add-to-list 'load-path (expand-file-name "lisp" user-emacs-directory)))

  (use-package p3-platform
    :ensure nil
    :demand t
    :config
    (p3/windows-configure-rtools))
#+END_SRC

** GnuPG

Prevent emacs from mangling the path to gpg on Windows, as shown [[https://emacs.stackexchange.com/questions/60278/gpg-no-public-key][here]]

#+BEGIN_SRC emacs-lisp
  (when (eq system-type 'windows-nt)
    (defun convert-windows-to-linux-path (windows-path)
      "Convert a Windows-style PATH (e.g., c:/foo) to Linux-style (/c/foo)."
      (let* ((path (replace-regexp-in-string "\\\\" "/" windows-path)) ;; Replace backslashes
             (path (replace-regexp-in-string "^\\([a-zA-Z]\\):" "/\\1" path))) ;; Add leading '/'
        (downcase path)))

    (setq package-gnupghome-dir
          (convert-windows-to-linux-path (expand-file-name "elpa/gnupg" user-emacs-directory))))
#+END_SRC

    :ensure nil
    :config

#+END_SRC

Interactive commands to connect to default connection.

#+BEGIN_SRC emacs-lisp

    "Connect to saved CONNECTION using SQL PRODUCT."
    (let ((sql-product product))
      (sql-connect connection)))

    "Connect to the saved ttuSql MySQL connection."
    (interactive)
    (p3/sql-connect 'mysql 'ttuSql))

  ;; Preserve the old command names for existing keybindings or muscle memory.

  (defalias 'my-sql-ttuSql #'p3/sql-ttu-sql)
#+END_SRC
